# Student Helpdesk System

A Java-based console application for managing student support tickets.

## 📌 Project Description

The Student Helpdesk System is designed to manage student complaints, queries, and support requests. It allows users to create, search, update, assign, track, and resolve support tickets through a menu-driven Java application.

## 🚀 Features

- Create support tickets
- View all tickets
- Search tickets by ID or keyword
- Update ticket details
- Update ticket status
- Resolve tickets
- Delete tickets
- Filter tickets by status
- View ticket statistics
- View tickets by priority
- Assign tickets to support staff
- Maintain ticket history
- Generate helpdesk reports
- Input validation and error handling

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Enum
- Java Collections
- IntelliJ IDEA
- Git
- GitHub
